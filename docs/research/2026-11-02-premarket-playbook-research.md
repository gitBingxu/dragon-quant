# 盘前预案 v2 调研：从“审计报告”到“盘中作战卡”

> 日期：2026-11-02｜类型：Full report｜Stakes：High（交易决策支持，不自动交易）
> 工作区：`docs/research/workspace/premarket-playbook-v2/`

## 结论先行

现有八段模板的问题不是“信息不够”，而是**组织方式不对**：它按数据域（信息截止 → 闸门 → 锚 → 主线 → 候选宽表 → 组合 → 验证 → 归因）展开，适合审计，不适合在 09:25–10:00 的几分钟内做决策。样本中的专业模板骨架高度相似，核心是**预先承诺**：先写清“今天什么情况下做什么、什么情况下什么都不做”，盘中只执行被信号确认的那一套。[1][2][5][9]

建议的新模板保留现有“事实 / 工作假设 / 行动”三栏与 `allowed_actions` 动作交集，但重排为：

1. **一页作战卡**（今日动作上限、风险预算、必须验证的 3 个问题、不做什么）；
2. **市场与主线剧本**（三向预期 + 可观察锚点）；
3. **候选逐只作战卡**（角色、冻结预期、trigger、invalidation、position_pct、时间窗、验证后 allowed_actions）；
4. **开盘后时间表**（09:15–09:20 / 09:20–09:25 / 09:25 / 09:25–09:30 / 09:30–09:35 / 09:35–10:00 / 午后 / 尾盘）；
5. **持仓与退出**（只引用现有 sell 规则）；
6. **不做什么 + 盘中更新纪律**；
7. **盘后归因**；
8. **证据附录与声明**。

核心变化是：把“四态条件”从一张表变成**逐时点可观察、可执行、可证伪的作战卡**；把“候选宽表”压缩成“每只一张卡”；把“无法交易”从最后一节提升为贯穿全模板的**不做什么清单**。

## 1. 外部范式：专业盘前计划到底写什么

### 1.1 英文实践：四栏、三情景、风险预算、检查清单

多个从业者模板的结构高度一致：

| 要素 | 具体做法 | 来源 |
|---|---|---|
| 标的数量 | 3–7 只 watchlist；SMB 写 3–5 个 ideas + 2nd day plays | [1][7] |
| 单票四栏 | bias（多/空/中性）、trigger（激活价）、invalidation（证伪价）、size（按止损距离与固定风险计算） | [1] |
| 单票五问 | bias、trigger area、invalidation、risk、no-trade zone | [4] |
| 情景脚本 | “If [condition] AND [zone], then [action] with size X and stop Y.” | [5] |
| 风险预算 | 单笔 0.5%–2%（默认 1%）、日亏上限、最大交易次数；到限即停 | [1][6] |
| 当日决策 | 正常交易 / 减小仓位 / 不交易；“stand aside”是有效结果 | [2] |
| 盘前检查 | 五问全 yes 才执行；四个 yes 跳过 | [1] |
| 盘中确认 | 突破回踩、VWAP 收复/拒绝、开盘区间突破、量能确认 | [4] |
| 不做什么 | 预先写“什么情况下什么都不做”；无法解释的跳空进 wait list | [3] |
| 盘后归因 | 计划 vs 实际、规则遵守、周度复盘 | [5][6][7] |

关键不是这些具体数字，而是**字段粒度**：只写“看多”不可执行；必须写到“哪个价位触发、哪个价位证伪、用多大仓位、什么时间窗口内有效”。TraderNest 的说法很直接：“If you cannot fill those four fields, the instrument does not belong.”[1] TheTwoTraders 也强调：“The scenario only tells you where to look; it is not an order.”[2]

SMB 的做法最接近“作战卡”：为每个 idea 预先设置价格提醒和 **pre-written trading scripts**，按 S1–S3 / R1–R2 价位写好多空情景，盘中只按脚本执行。[7]

### 1.2 中文 A 股实践：三向预期、竞价验证、情绪周期仓位

A 股短线的盘前预案有一套与美股不同的口径：

1. **三向预期**：符合预期可持有、超预期是新买点、不及预期是卖点；预案必须覆盖三向，缺一不可；“盘前做预案，开盘看信号，盘中做跟随”。[9] 另一篇同源实践把它压缩成一句操作口令：“低于预期放弃，符合预期看开盘盘面，超预期则竞价可以试错”，并强调“一字定方向”与封单稳定性。[10]
2. **竞价量化锚点**（自媒体经验，非官方规则）：超预期=高开 >3%、量能 ≥ 前一日 150%、封单加码；符合预期=开盘 ±1%、量能 80%–120%；不及预期=开盘跌超 1%、量能 <70%、封单撤。[12]
3. **情绪周期决定总仓位上限**：试错期 1–3 成、主升期 5–10 成、震荡期 3–5 成、退潮期 0–2 成；判据包括炸板率、连板高度、板块涨停家数。[13]
4. **分场景应对**：利好催化、主线龙头、趋势大盘股、利空落地、大盘指数，各自有超预期/符合/不及预期的动作；所有剧本都要带止损/止盈。[11]
5. **复盘四项**：大盘行情、情绪行情、龙头策略、明日操作；建仓前提是“大盘情绪、板块情绪、风口级别共振确认”。[14]

这些内容的共同点是：**盘前先定基准预期，开盘用竞价和分时信号选择剧本，盘中只跟随被确认的那一套**。但多数来源是自媒体/论坛，阈值口径不一致，且缺少统计验证；只能作为“经验基线”，不能写成项目规则。[12][13]

### 1.3 行为科学与交易制度：if-then 有用，但不是收益证据

Gollwitzer & Sheeran (2006) 的元分析覆盖 94 个独立检验（N≈8,461），发现 if-then 计划对目标达成有中等偏大效应（d=.65），机制是提高特定机会线索的可及性并自动化线索反应。[8] 但研究对象是健康行为、情绪调节、认知任务，**不是实盘交易**；把结论外推到交易属于理论推导，只能支持“降低临场决策负荷”的设计，不能支持“提高胜率”的承诺。

集合竞价制度则直接决定模板的时间骨架：9:15–9:20 可挂可撤，9:20–9:25 可挂但不可撤，9:25 集中撮合产生开盘价，9:25–9:30 只接受委托、不处理成交与撤单。[15][16][17] 因此 09:20 前的虚拟匹配价不能当事实，09:25 才是终态，09:25–09:30 不是新的竞价窗口。

## 2. 现有模板差距分析

| 维度 | 现有八段模板 | 外部范式 | 影响 |
|---|---|---|---|
| 组织方式 | 按数据域：截止 → 闸门 → 锚 → 主线 → 候选 → 组合 → 验证 → 归因 | 按交易时间线：盘前 → 竞价 → 开盘 → 盘中 → 尾盘 → 盘后 | 盘中要先翻过大量事实才能找到“现在做什么” |
| 候选呈现 | 12 列宽表 + 四态表 | 每只一张卡：bias/trigger/invalidation/size | 09:25 几分钟内无法逐列比对 |
| 时间表 | 09:25 / 09:30–10:00 / 之后 / 盘后 四行概括 | 逐时点检查清单 + 确认方式 | 不知道 09:30–09:35 具体看什么 |
| 结论 | 无“一页结论” | 当日姿态、风险预算、必验问题 | 用户要自己从闸门/仓位/锚中推导 |
| 不做什么 | 只有最后一节“无法交易与盘后归因” | 核心字段“什么情况下什么都不做” | 容易在数据缺失时临时找标的 |
| 更新纪律 | 无 | 计划固定、盘中只执行确认剧本 | 容易临场改计划、追价、被消息带走 |
| 确认方式 | “分时量价、收复/跌破、板块共振” | 突破回踩、VWAP、开盘区间、量能 | 缺少可观察、可复现的确认事件 |

现有模板的强项必须保留：事实与假设分离、时点分离、动作只取 `allowed_actions` 交集、不发明买点、不新增评分。问题只在**组织与粒度**，不是原则。

## 3. 新模板的设计原则

1. **结论先行**：第一屏给出今日动作上限、风险预算、必须验证的 3 个问题、不做什么；后续章节只是证据。
2. **一票一卡**：每只候选固定 8 个字段，填不满就标“缺失/未知”，不进入可执行清单。
3. **三向剧本 + 四态映射**：市场层用超预期/符合/不及预期；个股层仍用 `confirmed/weakened/invalidated/unknown`，两者用冻结预期 `gap_low/gap_high/ratio_low/seal_by` 连接，不新造阈值。
4. **时间轴检查点**：每个时点写“观察什么 → 满足什么 → 动作上限”；09:25 前不宣布 confirmed，09:25 后不得倒填。
5. **不做什么是一等字段**：数据缺失、计划不可用、硬风险、未核媒体、`gap_high` 之上无确认、账户未知、无触发 → 明确列为不做。
6. **更新纪律**：只允许“新官方证据 / 09:25 终态 / 开盘后确认”改变剧本；不允许改阈值、加候选、用未核媒体硬否决、用浮盈亏改计划。
7. **动作只来自交集**：`action_ceiling` + 资格 + `position_pct` + veto + `data_quality` + 账户闸门；验证通过后原样引用 `allowed_actions`，不自增“加仓/追高/抄底”。
8. **agent 可审计**：每张卡带来源与时点；缺失写缺失；事实、假设、动作分栏；盘后能逐条对照“计划 vs 实际”。

## 4. 推荐模板骨架（完整版见方案文档）

```markdown
# 盘前作战卡｜{trade_date}

## 0. 一页结论
- 今日动作上限：{wait / observe_only / no_new_position}（逐只列，不汇总成买入顺序）
- 风险预算：单票 position_pct 三态；账户闸门 unknown → 写未知；组合不归一
- 必须验证的 3 个问题：主线是否延续 / 龙头竞价是否达预期 / 是否有硬风险
- 今天不做什么：数据缺失不新建、未核媒体不硬否决、gap_high 之上不追、无触发不交易
- 信息截止 / 数据质量 / 降级

## 1. 信息截止与覆盖
（T、T-1 prep、frozen_at、created_at、strictness/proven_gap、auction state/as_of、外部证据覆盖率）

## 2. 市场与主线剧本
（T-1 市场状态/锚/主线/角色；三向预期的可观察条件；每档动作上限）

## 3. 主线与角色地图
（mainlines、leader/vanguard/mainstay/capacity/follower；确认/证伪条件；关注顺序 ≠ 买入顺序）

## 4. 候选逐只作战卡
（每只：身份/角色/血缘 → action_ceiling/position_pct/eligibility → 冻结预期 →
 三向剧本与无效条件 → 时间窗 → 验证后 allowed_actions → 证据/缺口）

## 5. 开盘后时间表与确认清单
（09:15–09:20 / 09:20–09:25 / 09:25 / 09:25–09:30 / 09:30–09:35 /
 09:35–10:00 / 10:00–11:30 / 13:00–14:30 / 14:30–15:00；每行：观察 → 确认/证伪 → 动作上限）

## 6. 持仓与退出
（逐只持仓/未知；T+1 可卖日；只引用现有 sell 规则；不因盘前预案改变卖出）

## 7. 不做什么 + 盘中更新纪律
（no-trade 清单；允许/禁止的更新；更新日志字段）

## 8. 盘后归因与明日输入
（哪套剧本发生；四态反馈；市场/模型/执行/数据归因；明日 prep 输入）

## 附录：外部证据清单 / 声明
```

完整模板（含占位符、硬约束与逐时点表）见 `docs/solutions/2026-11-02-premarket-playbook-v2-design.md`。

## 5. 局限与不确定性

- **外部证据以从业者经验为主**：英文来源多为交易博客/Prop firm 教育材料，中文来源多为自媒体/论坛；没有找到公开的、经过同行评审的“盘前模板有效性”研究。模板只能声称“更可执行、更可审计”，不能声称“提高收益”。
- **量化锚点口径不一致**：超预期高开 3% vs 6%、量能 150% vs 其他阈值，来源之间不一致；新模板应优先引用项目冻结预期 `gap_low/gap_high/ratio_low/seal_by`，只有在冻结预期缺失时才写“待竞价确认”，而不是搬用自媒体阈值。
- **行为科学外推缺口**：if-then 的效应量来自非交易领域；交易场景中的应用属于理论推导。
- **项目硬约束**：Skill 不输出买卖指令、不自动交易、不新增评分；新模板的“可执行”只能是“条件剧本 + 动作上限”，不是下单指令。
- **未覆盖**：科创板/创业板特殊交易机制、盘后固定价格交易、机构级内部 game plan 文档。
