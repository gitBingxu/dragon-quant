# 盘前预案调研与实现建议提纲

1. 核心答案：需要“只读快照上下文 + 当日外部证据 + 条件化模板”，不是 auction 报告改名。
2. 数据层：T-1 冻结计划、T auction 完整证据、T 外围/新闻三层的时点与血缘。
3. 为什么需要只读 premarket 命令：prep 会写、auction 投影不完整、SQL 不稳定。
4. 固定模板：信息截止与覆盖 → 市场/账户闸门 → 三锚 → 主线 → 候选四态 → 组合 → 验证 → 归因。
5. 信源与新闻：证据等级、去重、版本链、社交降权、缺失降级。
6. 行动约束：allowed_actions 与仓位/eligibility/veto 的交集，禁止新策略和收益承诺。
7. 实施分层、测试与非目标。
8. 局限：实时源 SLA、真实客户端工具差异、无全市场竞价、无真实成交与账户状态。
