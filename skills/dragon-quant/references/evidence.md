# evidence — 盘前外部证据（信源分级 / 时点 / 去重 / 冲突 / 降级）

**何时读我**：盘前需要采集政策、公告、外围行情与新闻，并判断它们是否改变 T-1 计划时。

## 信源层级（source_level）

1. `L1` 官方原文：政策原文、监管 / **交易所** / **公司公告** 与 PDF（政府网、交易所、巨潮、公司官网）。
2. `L1` 官方数据：官方指数、财政、央行、合约数据（FRED、SGX、US Treasury、Nikkei、KRX、LBMA/CME）。
3. `L2` 官方汇编与法定披露平台。
4. `L3` **媒体**（财联社等授权媒体）：发现线索，不替代原文。
5. `L4` **第三方**行情（Yahoo 等）：必须标第三方与时点。
6. `L5` **社交**帖 / 博客：只作待核实线索。

原则：**官方原文优先**；`L3` 及以下只能降低情景覆盖，不能单独改变结论。

## 每条证据必须保存

| 字段 | 含义 |
|---|---|
| `claim` | 一句话事实主张（不写推断） |
| `source_name` / `source_level` | 来源名称与层级（L1–L5） |
| `url` | 原文或官方页面地址 |
| `event_time` | 事件发生时间 |
| `publish_time` | 发布 / 披露时间 |
| `effective_time` | 生效时间（政策、合约、报告期） |
| `first_seen` | 首次抓取时间（crawl time） |
| `retrieved_at` | 本次复核时间 |
| `instrument` / `company` | 相关标的或公司 |
| `correction_of` | 更正 / 补充版本链（指向旧版本） |
| `verification_status` | 见下表 |

`verification_status` 取值：

- `official_original`：已核官方原文；
- `official_quote`：官方来源转述，未读全文；
- `media_unverified`：媒体转述，**未核原文**；
- `social_lead`：社交线索，未核实；
- `not_available`：本环境无法获取；
- `login_required`：需要登录授权。

## 时区与口径

- 美股用美国观测日；A 股盘前引用时必须写明观测日，不写成「今天」。
- 日经 / KOSPI 在 A 股盘前是**盘中快照**，标实际时点。
- A50 保留合约月、会话与最后价类型；10Y 是官方 CMT 日频；黄金 LBMA / COMEX / XAU 分列，不混算。
- 同一品种不同**口径**不合并（现货 / 期货 / 指数 / 汇率）。
- 时点、时区、口径都属于事实栏，不允许省略。

## 去重

- 同一公告按官方 ID / PDF URL / 公司 + 公告编号**去重**；多家转载算一条来源，保留最高层级。
- 同一事件的不同报道只保留一条主记录，其余进 `correction_of` 或备注。
- 同一股票多份公告按事件聚合，不重复计入「新增硬风险」。

## 冲突与更正

- 冲突时高层级来源优先；`L3` / `L5` 与官方冲突时以官方为准，并记录冲突。
- **更正** / 补充保留版本链，不覆盖旧版本；报告引用最新有效版本并注明旧版本。
- 只有媒体转述、未核原文 → `media_unverified`，**不得直接硬否决**候选，只能写「待核实」或降低情景覆盖。
- `L5` 社交线索不进入事实栏，只进待核实清单。

## 降级

- 外围缺失只降低情景覆盖，**不填中性**、**不当作利好**。
- 覆盖率必须显式写：例如「政策已核 2 条 / 公司公告 3 家 / 官方行情缺失」。
- 宿主无网页 / 搜索工具时写「本环境无法获取，覆盖率为 0」，并降低情景覆盖；不得假装已核验。
- 需要**登录**时提示用户授权；**不逆向**私有 APP 接口、**不伪造** Cookie、不回显凭据。
- 证据不足时，情景只能写「无法判断」，行动只能 `observe_only`。

## 证据如何进入盘前预案

- 事实栏：`claim` + `source_level` + `event_time` / `publish_time` + `url`。
- 工作假设：隔夜证据**是否改变** T-1 计划逻辑；媒体未核原文不算改变。
- 行动：只有「硬风险」才取消 / 不新建；`media_unverified` 只写待核实。
- 附录：逐条输出 `claim / source_name / source_level / url / event_time / publish_time / effective_time / first_seen / verification_status / 用于段落`。
