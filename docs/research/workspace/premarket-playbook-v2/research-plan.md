# Research Plan — 盘前预案模板 v2（面向盘中操作）

- 日期：2026-11-02
- 证据截止：2026-11-02
- 输出类型：Full report（研究结论 + 模板设计建议）
- Stakes：High（交易决策支持，但不自动交易）
- 受众：dragon-quant 项目维护者 / `dragon-quant` Skill 使用者
- 地域/市场：A 股（T+1、涨跌停、集合竞价、龙头战法），借鉴美股/期货日内交易计划范式

## 研究问题

1. 专业交易者/交易社区的盘前预案（pre-market plan / game plan）通常包含哪些结构？
2. 这些结构如何把盘前计划转成盘中可执行的动作（触发条件、情景分支、仓位与风控、盯盘清单、失效条件）？
3. A 股短线/龙头战法的盘前预案有哪些特有口径（集合竞价、情绪周期、三向预期、仓位分档）？
4. 现有 `dragon-quant` 盘前模板（八段）与上述范式相比，缺什么、为什么“对盘中帮助不大”？
5. 对 AI agent 而言，模板应如何组织，才能既可执行又不越过项目硬约束（不发明阈值、不输出交易指令、可审计）？

## 研究线程

- A. 英文专业交易计划 / pre-market routine / if-then 模板。
- B. 中文 A 股短线盘前预案、情绪周期、集合竞价三阶段。
- C. 行为科学证据（implementation intentions）与交易所集合竞价规则。
- D. 现有模板对照与差距分析（项目文档）。

## 判定标准

- 每个模板要素至少有一个可访问来源支撑；区分 practitioner heuristic 与官方规则/学术证据。
- 明确哪些数字是来源阈值，哪些只能引用项目冻结预期（`gap_low/gap_high/ratio_low/seal_by`）。
- 最终模板必须能在 300 行内表达，且不违反 Skill 的安全边界。

## 证据边界

- 中文自媒体内容只作实践参考，不作为权威规则；无法访问原文的条目降级为“搜索摘要，未核原文”。
- 美股日内模板不能直接套用到 A 股 T+1/涨跌停/竞价制度，只提取结构。
