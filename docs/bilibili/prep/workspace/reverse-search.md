# Reverse search — 可能推翻方案的证据与失败模式

- **在线可用性**：stock-ana 只证明代码与离线文档，未证明 2026-10-28 端点仍可用。若关键字段实测覆盖率不足，应降低来源等级，而不是用 OCR 或中性分补齐。
- **历史口径**：板块成员、竞价、封单时序无法完整回补。若训练/回测依赖这些字段，只能从真实采集日开始前向评估，不能用 OHLC 历史伪装长样本。
- **评分过拟合**：多篇材料没有样本外证据。若简单基线（现有五维 + 当前情绪闸门）在滚动样本外不劣于复杂评分，应拒绝上线复杂权重。
- **角色误判**：主线/龙头身份若只靠单日排名，可能把高潮和一致误判为最强买点。需专门检验高潮次日与高位负反馈样本。
- **Agent 失控**：自然语言可能把“观察”写成“买入”、把缺失写成利空，或发明阈值。Skill 必须只消费结构化动作枚举与理由代码，并对缺失/降级有禁止表述。
- **独立单票仓位的代价**：按用户要求不做组合归一，多个建议同时出现时总仓位可能超过 100%。产品必须明确它们是彼此独立的单票上限/建议，不是可同时照单全收的组合指令。
- **兼容事故**：旧 verdict 和 sentiment.position_pct 已影响下游。若迁移改变默认值，可能在无人工确认时改变 buy/sell；必须版本化并默认影子运行。
- **合规与稳定性**：免登录/公开 endpoint 不等于允许再分发，也无 SLA。网页登录态只能由用户授权提供，凭证不得入库或出现在报告/截图中。
