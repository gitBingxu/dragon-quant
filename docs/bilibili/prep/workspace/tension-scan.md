# Tension scan

1. **“复盘高分”不等于“明日可买”**：个股质量、T 日强度、T+1 触发条件是三个不同机制。可检验方式：分别评估质量分、次日条件与最终收益/回撤，禁止用一个混合总分掩盖时点差异。
2. **“涨停最多/涨幅最高”不等于“可持续主线”**：板块持续性可能更依赖梯队完整度、核心股反馈、扩散与分歧修复，而非单日排名。可检验方式：对比单日强度与多日持续、晋级、回流的解释力。
3. **“因子更多”不等于“决策更好”**：重复因子会放大同一风险，事后阈值容易过拟合，网页缺口还可能被错误填成中性。可检验方式：做因子相关/共线性检查、样本外与滚动验证、缺失消融，并保留简单基线。
