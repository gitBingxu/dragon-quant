# 复盘方法论（自动化落地版）

> 从 5 份游资/职业交易员复盘材料（华东导弹、无名游资、江浙陈某、短线狂徒张三、万战寻道）中提炼、经 4 路因子辩论裁剪后的**可自动化落地的盘后复盘方法论**。
> 目标：在盘后（T 日收盘后）前置挑选候选池，供 T+1 日 review-account / buy-sell 买入，替代现有"最近 3 日真龙并集"的硬性候选池。

---

## 一、设计原则（四条铁律）

1. **无未来函数**：候选池与情绪温度只用 T 日及之前数据（T+1 买入）。任何依赖 T+1 开盘数据的"超预期/低预期"判据，一律拆成"T 日预计算预期基准 + T+1 盘中比较"，触发逻辑下沉 strategy 层。
2. **盘后只放客观量化因子**：逻辑可持续性、情绪周期节点等主观/合成概念，不作为盘后原始因子；要么人工标注加分，要么作为其它因子的合成输出。
3. **不重复五维评分**：先锋/龙头判定已被带动性(封板最早)/流动性(换手封板质量)/领涨性(连板最多)覆盖；龙头定位层只补"辨识度/风格"类弱因子。
4. **分层职责清晰**：情绪温度 = 仓位闸门（能不能做、上几成）；主线识别 = 选方向；龙头定位 = 选个股；择时 = 全部下沉 strategy。

---

## 二、总结构（三层漏斗 + 一个择时闸门）

```
[0 情绪温度闸门]  涨跌停比 · 涨跌家数比 · 连板梯队 · 昨日涨停溢价 · 量能
                  → 仓位档位：空仓 / 轻仓(2-3成) / 正常(6-8成)
        ↓ 通过
[1 主线识别]      涨停分布集中度(哪个行业涨停家数最多) + 主动性确认(超额+放量+封板早)
                  → 锁定 1-3 个主线板块
        ↓
[2 龙头定位]      主线板块内当日涨停股 → 五维评分(已有) + 最高标/中军/股性/成交额/风格标签
                  → 候选池（T+1 可买名单）
        ↓
[3 前瞻输入字段]  距前高/距MA5 · 异动节奏 → 盘后预计算，供 T+1 盘中 strategy 消费
```

## 三、逐层落地规格

### Layer 0 — 情绪温度闸门（择时 / 仓位）

| # | 因子 | 计算口径 | 数据源 | 未来函数 | 落地 |
|---|---|---|---|---|---|
| 0.1 | 昨日涨停今日表现 | T-1 涨停名单在 T 日的晋级率 + 平均溢价率 | T-1 涨停名单(统计板块成分) + 腾讯今开/昨收 | 无 | **采纳·核心** |
| 0.2 | 涨跌停家数比 | 全市场涨停家数 vs 跌停家数（主板±10%/双创±20%/ST±5% 分板计数） | 腾讯批量行情全市场扫描 | 无 | **采纳·核心** |
| 0.3 | 连板高度序列 | 近 3 日最高连板数及梯队变化（趋强/退潮，如 13→7→5） | 雪球/TDX 日 K 算连板 | 无 | **采纳·核心** |
| 0.4 | 涨跌家数比 | 全市场上涨/下跌家数 | 腾讯批量行情 | 无 | **采纳** |
| 0.5 | 量能流动性区间 | 两市成交额区间（万亿 vs 5000-7000 亿）及放缩量趋势 | 指数/全市场成交额汇总 | 无 | **采纳·仓位闸门** |
| — | 指数量价关系 | 放量涨/缩量虚高 | 腾讯/TDX 指数 | 无 | 降级·背景 |
| — | 炸板率 | 炸板/(涨停+炸板)，阈值 <20% 强 | TDX 分时摸板 / 涨停池 | 无 | 降级·二期（可先以"曾涨停"近似） |
| — | 高位 vs 低位 | 高位抱团/高标瓦解 | 分层池+今日表现 | 无 | 降级·与 0.1/0.3 共线 |
| — | 投机主战场 | 板/创/科的涨停分布 | 代码前缀 60/00/30/68 拆分 | 无 | 降级·风格因子 |

**输出**：`情绪温度评分 + 仓位档位`。作为 review-account 与 buy/sell 共用的择时闸门（情绪差 → 空池或收缩仓位）。

### Layer 1 — 主线识别（选方向）

| # | 因子 | 计算口径 | 数据源 | 未来函数 | 落地 |
|---|---|---|---|---|---|
| 1.1 | 涨停分布集中度 | 全市场涨停股按 881xxx 行业归组计数，取最多板块 | TDX 涨停板块成分 或 腾讯全市场扫描 + 行业归属 | 无 | **采纳·主信号** |
| 1.2 | 主动性/被动性 | 板块相对上证超额 + 板块成交额环比放量倍数 + 涨停股封板时间中位数(早=主动) | TDX/同花顺板块 1分K/5分K + 腾讯盘口 | 无 | **采纳·质量确认** |
| 1.3 | 板块涨幅榜前三 | 领涨行业 Top3 | TDX/同花顺行业排行(现有 Phase A) | 无 | 降级·初筛背景 |
| — | 进攻 vs 防御 | 科技成长=进攻/银行周期=防御 | 静态板块风格标签 | 无 | 降级·仓位乘数 |
| — | 逻辑可持续性 | 利好持续性/社会话题热度 | 舆情源(官媒/财联社) + NLP | 需界定 T 日时点 | 降级·人工标注加分(二期) |

**规则**：`涨停家数最多 且 主动放量` 的板块才是可买入主线；板块涨幅前三仅作初筛缩小范围。

### Layer 2 — 龙头定位（选个股）

**候选基础**：主线板块内当日涨停股（现有 Phase B，过滤 ST/双创/北交所）。
**评分主核**：五维评分（带动性 30 / 领涨性 25 / 抗跌性 15 / 流动性 20 / 资金承接 10）——已覆盖先锋/龙头判定。

| # | 增量标签 | 计算口径 | 数据源 | 未来函数 | 落地 |
|---|---|---|---|---|---|
| 2.1 | 全市场最高标 | 全市场最高连板股（全局情绪辨识度） | TDX/雪球日K连板排序 | 无 | **采纳** |
| 2.2 | 中军标签 | 大市值(>200亿)且涨停 | 腾讯市值 + 当日涨停 | 无 | **采纳·容量标签** |
| 2.3 | 股性 | 历史涨停次日胜率/溢价（时间衰减防过拟合） | 雪球/TDX 历史日K 横截面 | 无 | **采纳·弱加权** |
| 2.4 | 成交额软下限 | 日成交额 > ~3 亿（不硬砍小盘真龙） | 腾讯 f[36] | 无 | **采纳·软过滤** |
| 2.5 | 市值/形态风格标签 | 小市值偏好 / N字/突破/二波形态 | 腾讯 + VPA(breakout/trend_verify) | 无 | **采纳·条件标签** |
| — | 主力成本/量价 | 主力建仓成本、涨幅 vs 成本 | 免费源无分笔/L2/筹码分布 | 误差大难验证 | **丢弃** |

### Layer 3 — 前瞻输入字段（下沉 strategy）

| # | 字段 | 计算口径 | 归属 | 落地 |
|---|---|---|---|---|
| 3.1 | 异动节奏 | 板块+个股 1分K 异动时点聚类（时间一致性→资金/消息） | 盘后候选池因子 | **采纳**（唯一纯盘后增量） |
| 3.2 | 位置字段 | 距前高 / 距 MA5 距离 | 盘后预计算输入 | 降级·输入字段 |
| — | 修复/分歧推演 | 次日修复还是分歧 | 盘中 strategy | 降级·已有"分歧买龙/突破前高" |
| — | 超预期/低预期 | 开盘 vs 预期基准 | 盘中 strategy | 降级·未来函数风险最高，最后做 |

## 四、与现有系统的映射

| 复盘层 | 现有能力 | 需新增 |
|---|---|---|
| 0 情绪温度 | 无（全市场扫描能力未接） | 腾讯全市场批量扫描 + 统计板块成分拉取 + 情绪温度模块 |
| 1 主线识别 | Phase A 领涨行业 Top5、Phase B 领涨行业涨停股 | 涨停分布集中度(全市场涨停按行业归组) + 主动性计算 |
| 2 龙头定位 | 五维评分、连板天数、concepts、换手/成交额/市值 | 最高标/中军/股性标签 + 成交额软下限 |
| 3 前瞻字段 | strategy 已有 MA5/突破前高/分歧买龙 | 异动节奏 + 位置字段预计算 |
| 候选池 | `collect_candidates` = 3 日真龙并集 | 替换为"主线龙头 + 最高标 + 昨日涨停晋级者" |

**关键数据源确认（已核代码）**：
- `orchestrator.py:37-42` `STATISTICAL_CONCEPT_PREFIXES` 暴露通达信概念板块含"昨日涨停/昨日连板/昨日炸板/昨日跌停/昨日触板/最近多板"，当前被 `_sector_ok`(line 446) 过滤。**取这些板块成分股即可得涨跌停/炸板名单**（需验证 tdx.py 是否暴露 `BoardType.GN`；若无则回退同花顺概念板块或腾讯全市场扫描）。
- `tencent.py:90` 行情已含 `limit_up/limit_down/换手/成交额/市值`。
- `xueqiu.py:143` 已有"复盘炸板检测"的 5 分钟 K 注释（炸板率二期可复用）。

## 五、落地路线图

### Phase 1（最小可用 · 替代 3 日真龙并集）
- 候选池来源改为：`主线板块(涨停分布集中度)内的当日涨停龙头 + 全市场最高标 + 昨日涨停今日晋级者`。
- 情绪温度闸门：`涨跌停家数比 + 涨跌家数比 + 量能` → 仓位档位。
- 落地位置：`review_account/market.py` 新增候选池构建函数 + `dragon_quant/` 新增情绪温度模块；CLI 接入 `review-account` / `buy` / `sell`。

### Phase 2（增量标签 + 择时输入）
- 龙头增量标签：中军 / 股性 / 成交额软下限 / 风格标签。
- 主线质量确认：主动性/被动性。
- 前瞻输入字段：距前高/距MA5、异动节奏。

### Phase 3（二期 / 可选）
- 炸板率（需分时摸板）。
- 逻辑可持续性（舆情源接入，人工标注起步）。

## 六、因子裁决总表（附理由）

> 完整辩论细节见 session 内 4 路因子研究员报告。此处保留最终结论。

| 因子 | 裁决 | 核心理由 |
|---|---|---|
| 昨日涨停今日表现 | ✅ | 对打板接力区分度最高，T-1 名单+腾讯今开/昨收，成本低 |
| 涨跌停家数比 | ✅ | 情绪极值核心，腾讯按板计数 |
| 连板高度序列 | ✅ | 情绪趋强/退潮，雪球/TDX 日K |
| 涨跌家数比 | ✅ | 广度情绪核心，腾讯批量 |
| 量能流动性区间 | ✅ | 仓位闸门，两市成交额汇总 |
| 涨停分布集中度 | ✅ | "主线"最强代理，涨停潮聚集处=资金主战场 |
| 主动性/被动性 | ✅ | 剔除被指数带起的伪主线 |
| 全市场最高标 | ✅ | 全局情绪辨识度，五维未覆盖 |
| 中军标签 | ✅ | 容量标签，腾讯市值+涨停 |
| 股性 | ✅(弱) | 历史胜率/溢价，需时间衰减 |
| 成交额软下限 | ✅(软) | 有资金才有行情，~3亿软下限 |
| 异动节奏 | ✅ | 唯一纯盘后择时增量，1分K时点聚类 |
| 指数量价 / 炸板率 / 高位低位 / 投机主战场 | ⬇️ | 噪音或共线或需分时，降级/二期 |
| 板块涨幅前三 / 进攻防御 / 逻辑可持续性 | ⬇️ | 初筛背景 / 仓位乘数 / 需舆情源 |
| 压力支撑位 / 修复分歧 / 超预期 | ⬇️ | 位置字段盘后预计算，触发下沉 strategy |
| 情绪周期节点 | ❌ | 是①②③的合成输出，非原始因子 |
| 主力成本/量价 | ❌ | 免费源无分笔/L2/筹码分布，误差大不可验证 |
| 先锋/龙头(显式) | ❌ | 已被带动性/流动性覆盖 |
