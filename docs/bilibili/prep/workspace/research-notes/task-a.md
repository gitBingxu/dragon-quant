### [1] 万战寻道：客观原则、回顾—前瞻、两套复盘路径

#### 1) 复盘先后顺序与决策流程

- 第一原则是客观：涨了就是涨了、跌了就是跌了；不能用主观喜好、持仓立场或单一维度替代证据，即使持有看空标的也应承认看空。[1, L22-L30][1, L255-L266]
- 总框架是“回顾 + 前瞻”，两者同等重要。回顾先梳理当天行情、核心表现、重要信号或重大变化，再追问变化原因；前瞻基于原因和逻辑推演多种可能，并分别制定应对方案。[1, L34-L42][1, L63-L72][1, L99-L122][1, L849-L852]
- 回顾不是只报涨跌。例如先看到能源金属最强，再追到转融券/融券比例逻辑，再估算潜在买盘规模，最后形成“持续性预期不好”的前瞻判断。[1, L41-L68]
- 前瞻的最小决策链是：正常预期是什么 → 小概率超预期是什么 → 用什么信号识别超预期 → 超预期后做谁 → 对应二波、反抽、低位等哪种机会 → 制定不同计划。[1, L71-L122]
- **模式型复盘自下而上**：先按模式核心（案例为一进二图形审美）筛首板，再依次叠加市值、题材、股性、市场风格、次日接力情绪，最后决定标的和仓位。案例从 50/30 只筛到 5/3 只，再筛到 3—4 只，只是流程示例，不是固定入选数。[1, L131-L160][1, L161-L190]
- **理解力型复盘自上而下**：指数整体预期 → 情绪 → 题材板块 → 板块核心/潜力标的 → 操作节奏和仓位。作者强调短线不能“重个股轻指数”，越大层级越能决定整体节奏。[1, L196-L247]
- 最后复盘自己的交易：每天找“最优解”（做过或没做过都可），记录其成立维度；复盘亏损、盈利中“看懂却卖飞”的交易及大回撤，区分市场、模式、执行力和心态原因。[1, L267-L280][1, L287-L333]
- 流程是持续纠偏而非次日必中：复盘本质是概率推演，计划失效时要检查客观性、回顾/前瞻是否充分、是否只看图形而漏掉大层级与仓位匹配。[1, L248-L266][1, L815-L818]

| 因子 | 原文口径、数字和否定条件 | 来源 |

| 流动性变化预期 | 不只看当日量，还看后续放量/缩量倾向。案例中成交额从 5000 多亿元快速放到 7800 亿元，若无后续利好，作者把它视作短期偏极限量值，预期后续整体缩量、题材延续性不佳。 | [1, L369-L390] |
| 流动性变化驱动 | 消息面、赚钱/亏钱效应刺激、关键技术位突破或跌穿都会影响后续量能；压力位附近买盘可能减少。 | [1, L393-L408] |
| 支撑/压力与筹码结构 | 结构线、均线、支撑、压力用于给出具体行动点位；观察到位后的拐头、强弱和量能。大支撑/压力通常不轻易突破，必须看突破或触及时的力度与量。20 日线是当日案例压力，不是通用阈值。 | [1, L410-L438] |

| 外力方向 | 汇率、外围、消息是外力；同向外力通常加速原方向，反向外力通常阻挠/延缓而不轻易改变方向，特别重大外力除外。 | [1, L477-L529] |
| 高位利好/低位利空 | 涨十倍后兑现十倍业绩，不一定再构成向上空间；已跌 80% 后公布业绩同比减少 80%，可能是做空预期已提前兑现。高位同向利好虽可能令当日加速，却可能损害后续持续性。 | [1, L495-L521] |

| 生态持续性 | 生态不是一天的小规律，不能因创业板一天约 10 个涨停就确认生态转好，也不能因主板一天约 70 个涨停就确认已从创业板切到主板；生态开启和结束都通常不是一日完成。 | [1, L563-L597] |
| 主流形态偏好 | N 字、突破、超跌、二波等。N 字案例称当时打板次日有 10% 以上兑现机会、当日加隔日可能 20%—30%，是特定一周历史案例，不是未来收益阈值。 | [1, L599-L625] |
| 股价偏好 | 弱市案例偏好一两元低价股；属于阶段性风格，不是永久规则。 | [1, L626-L631] |
| 市值偏好 | 案例称当时连板股没有流通市值大于 25/30 亿元者，因此做 31/41 亿元的一进二失败概率偏高；同时明确并非永远偏小市值，行情好时 300 亿元市值也可连板。 | [1, L632-L641] |
| 走势偏好 | 比较板块内趋势与接力谁更强；若板块只有趋势股持续抬升、连板缺失，就应优先趋势而非硬做连板。 | [1, L642-L670] |
| 情绪大趋势 | 用龙头高度序列等判断趋强/趋弱：案例中高度由 13 板、13 板降至 7 板、7 板再到不足 5 板，视为趋弱，继续顶高位性价比差。 | [1, L671-L689] |
| 隔日小趋势 | 判断次日修复/分歧，并结合大趋势。压力位的次日分歧、支撑位的次日修复相对容易判断，中间段无法每天精确判断；此时顺大方向、控仓或不做。 | [1, L689-L729] |
| 逆趋势修复 | 大方向向下时，即使判断次日修复，也按隔日套利而非反转处理，降低预期和仓位；正趋势中的修复才可更乐观。 | [1, L730-L741] |
| 高位/低位强度 | 健康正向市场案例：高标由 7 板进 8 板，低位涨停由 30 家增至 50 家，高低位共同增强。弱势震荡中高低位可能跷跷板，高位抱团不等于能带动低位。 | [1, L751-L787] |

#### 3) 维度分类

- 指数维度分为**内在因素**：流动性（区间、变化预期）、筹码结构（支撑/压力）、资金载体（进攻/防守、主动/被动）；**外在因素**：汇率、外围、消息，并判断同向或反向。[1, L345-L348][1, L410-L476][1, L477-L529][1, L860-L861]
- 情绪维度先分**生态**与**情绪本身**：生态看投机方向和主流风格；风格再分形态、股价、市值、走势偏好。情绪本身看大/小趋势、修复/分歧以及高位/低位赚钱效应。[1, L535-L544][1, L595-L671][1, L671-L688][1, L751-L788][1, L862-L865]
- 题材层级位于指数和情绪之后，继续看板块表现、预期、核心及潜在上涨标的；本场未展开题材细节。[1, L237-L247][1, L813-L814]
- 自我交易维度分最优解、亏损、盈利中卖飞、大回撤，并归因到市场、模式、执行或心态。[1, L267-L333]

#### 4) 主线、龙头、情绪锚和角色判定

- 主线/题材不能只看当天涨幅，要追溯上涨原因、逻辑容量和流动性环境；被动被市场带涨的板块，次日正常预期偏分歧/回调。[1, L41-L68][1, L73-L100]
- 龙头高度是情绪趋势的观察锚：连续龙头最高板下降代表高度压缩；高标与低位涨停家数的组合用于辨别健康共振还是弱势抱团。[1, L677-L689][1, L751-L787]
- “空头龙”是风险锚：开盘集体不及预期、空头龙继续杀跌或其杀跌超出预期，被用于解释接力情绪崩溃，而不是把亏损简单归咎于个股模式。[1, L280-L292]
- 龙头还可承担生态锚作用：案例称创业板十倍龙头带动整个创业板赚钱效应，但单日涨停数量不足以确认生态切换。[1, L563-L580]
- 角色选择服从市场偏好：板块趋势强就优先趋势核心，情绪趋弱时不因单日修复而盲目顶高位；二波确认时看二波核心而非一律切低位。[1, L112-L118][1, L642-L670][1, L683-L689]

#### 5) 次日正/负反馈与应对

- **正常负反馈**：前一日被动上涨的板块，正常预期为次日分歧/回调；若判断没有日内博弈价值则不做，若一定要参与，只倾向尾盘判断后日修复。[1, L79-L100]
- **超预期正反馈**：指数冲高回落或下杀时，板块表现明显抗跌，或主动分离上涨，属于超预期识别信号；若进一步确认二波突破，再选择二波标的。[1, L102-L119]
- 主动放量、无消息刺激、由空转多的主动做多，使后续回调相对更有安全性；被动跟涨不能得到同样结论。[1, L455-L475]
- 大趋势向下中的次日修复只按套利、低仓位处理；大趋势向上时的分歧可相对乐观。方向不明的中段不做或控仓。[1, L714-L741]
- 同向消息可能带来高开加速但透支后续；反向消息一般先造成回调/延缓而非直接反转。高位利好、低位利空都要先检查是否已兑现。[1, L495-L521]
- 对“杂毛”持仓，可升维用次日指数节奏决定是否能格局到尾盘，而非只盯个股分时。[1, L199-L234]
- 看懂仍因分时恐慌卖出被归为心态/执行问题；作者建议不要在恐慌一致的急杀中卖出，可事先锚定收盘再处理。卖飞本身不必然是错误，只有原判断仍支持持有却提前卖才列入此类复盘。[1, L293-L317]

#### 6) 可量化项、需计算派生项、主观判断项（研究归纳）

- **可直接量化**：全市场成交额、上涨家数、各板块/市场涨停家数、连板高度、流通市值、股价、支撑/压力位、个股及账户回撤、主板/创业板涨停数量。
- **需派生或序列化计算**：成交额所处历史区间及后续缩放量趋势；龙头高度序列的斜率/压缩；高位高度与低位涨停家数是否共振；题材/个股相对指数的抗跌与主动分离；不同形态、价位、市值、趋势/接力风格的阶段胜率；单笔回撤相对平均盈利和赔率是否过大。
- **主观/需额外定义**：消息是否重大及是否已兑现、板块进攻/防守归类、主动做多与消息刺激的区分、生态是否已开启/结束、支撑压力是否有效、二波确认、情绪拐点、最优解，以及“看懂却卖飞”与正常卖出的区分。
- 原文提到“四种判断隔日情绪的方法”和题材的预期差，但本场没有给出四种方法清单或题材细则，不能从本文补齐。[1, L173-L180][1, L692-L695][1, L813-L814][1, L828-L829]

### [2] 短线狂徒张三：大盘—板块—个股三步与量化仓位

#### 1) 复盘先后顺序与决策流程

- 复盘目的先定为三项：判断赚钱/亏钱效应以调仓；锁定资金聚集的主流板块；复盘对错交易以优化体系。避免只搬数据、只看指标而忽视自身情绪、只总结今天而不制定明天动作。[2, L22-L30]
- 三步顺序：**盘后大盘数据处理 → 题材板块与核心识别 → 个股持仓及操作检查**。[2, L31-L45][2, L45-L69][2, L69-L77]
- 大盘先记录成交量与指数、涨跌家数、涨跌停家数、炸板率，得到总体强弱；板块再看涨幅/涨停家数靠前的方向、板块性质及核心角色；个股检查是否主流、消息和止盈止损。[2, L33-L44][2, L50-L71]
- 个股操作前“三问”：买入逻辑是什么；买后是否有资金封板；若有封板，次日什么资金接力，若无封板，是否有资金反包。[2, L72-L76]
- 用表格和交易日志记录方向、龙头、涨跌停/炸板数据、买卖点、开仓点位、胜率、盈亏比，再制定次日计划：仓位 → 选股 → 买点 → 预期一致与否的处理。[2, L78-L111]
- 执行上先练三步并坚持记录，再逐渐加指标，避免完美主义；另建错题本，阶段复盘错误。[2, L112-L133]

#### 2) 明确因子、口径与阈值

| 因子 | 原文口径、数字和否定条件 | 来源 |
|---|---|---|
| 量价组合 | 指数放量上涨被视为健康上涨，可继续期待次日；指数上涨但无量被视为虚高，需防次日回落；放量下跌且抛压重则可能持续下跌。 | [2, L33-L38] |
| 涨跌家数比 | 比较上涨与下跌家数感知市场情绪；下跌四五千家、上涨仅数百家代表行情和情绪差，应控仓。 | [2, L39-L40] |
| 涨跌停家数 | 涨停多、跌停少则情绪较好；另与炸板率共同判断短线情绪。 | [2, L40-L43] |
| 炸板率 | **低于 20%** 被称为强势市场；**高于 20%** 代表情绪不佳、封板分歧大，要降仓。恰好 20% 未定义。案例中非一字涨停 80+、跌停 52+、炸板 26 家，讲述者称“明显超过 20%”，但稿件未给完整计算分母。 | [2, L41-L43][2, L80-L83] |
| 热门板块排名 | 通过板块涨幅及涨停家数排序，通常只看**前三名**，认为资金有限时应聚焦最核心方向。 | [2, L50-L56] |
| 板块进攻/防御 | 科技、人工智能等归为进攻型；银行、房地产、周期股归为防御型。进攻板块领涨时可放大仓位，银行保险等防御板块领涨时降低仓位。 | [2, L56-L63] |
| 先锋 | 板块内**率先涨停且非一字板**的股票。 | [2, L63-L65] |

| 龙头 | 原文并列“流动性最强、带动性最强、涨幅最高/涨得最快”，并称其最容易赚钱；聚焦龙头优于买后排。稿件在“流动性”处有重复，不能进一步推断其精确排序公式。 | [2, L65-L68] |

| 交易质量 | 持续统计买卖点、开仓点位、胜率、盈亏比，用于识别交易特征和纠错。 | [2, L83-L87] |

#### 3) 维度分类

- 市场层：指数、成交量、涨跌家数、涨跌停家数、炸板率，输出总体情绪和仓位。[2, L33-L44]
- 板块层：资金主战场、热门前三名、进攻/防御性质、板块核心。[2, L45-L68]
- 个股角色层：先锋、中军、龙头；操作层再分封板、接力、反包、消息和止盈止损。[2, L63-L76]
- 自我与计划层：交易日志、胜率、盈亏比、错题本，次日仓位、选股、买点和预期处理。[2, L78-L111][2, L123-L132]

#### 4) 主线、龙头、情绪锚和角色判定

- 主线是“有逻辑且有大资金流入”的热点板块，实操上以涨幅和涨停家数排名前三来聚焦，而非研究所有冷门方向。[2, L45-L56]
- 龙头、中军、先锋按上表角色定义区分；核心标的从每个前三板块中提取并记录。[2, L63-L68][2, L78-L82]
- 情绪锚主要是涨跌停家数和炸板率；板块领涨性质还充当市场进攻/防御状态锚。[2, L40-L43][2, L56-L63]
- 持仓必须检查是否属于主流；非主流、低成交额和后排不作为优先对象。[2, L69-L71][2, L94-L104]

#### 5) 次日正/负反馈与应对

- 放量上涨 → 可继续期待次日；无量上涨 → 视为虚高、防压回；放量下跌 → 防连续下跌。[2, L35-L38]
- 涨停多、跌停少、炸板率低 → 情绪好；炸板率高于 20%、涨停少 → 降仓。进攻板块领涨可放大仓位，防御板块领涨则降仓。[2, L40-L43][2, L56-L63][2, L88-L93]
- 买入后有资金封板，还要预判次日接力资金；没有封板则看是否有反包资金，不把封板本身当成全部决策。[2, L72-L76]
- 次日走势与预期一致可继续持有，与预期不一致则按原文意思尽早处理；具体止损幅度未给。[2, L109-L111]

#### 6) 可量化项、需计算派生项、主观判断项（研究归纳）

- **可直接量化**：指数涨跌、成交额、上涨/下跌家数、涨停/跌停/炸板家数、板块涨幅和涨停数排名、个股市值、成交额、仓位比例、交易时间、胜率、盈亏比。
- **需派生计算**：炸板率及其 20% 判定、涨跌家数比、量价组合状态、板块多指标综合热度、角色候选排序、逐笔交易日志的胜率与盈亏比。
- **主观/需额外定义**：大资金流入背后的“逻辑”、进攻/防御分类（尤其周期股的固定归类）、龙头多项“最强”的权重、预期是否一致、封板后接力与反包资金是否存在、关键价位突破和自选系统买点。
- 20% 炸板率、60%—80%/20%—30% 仓位、5/10 亿元成交额和 200 亿元中军市值都是本文明确数字，但没有样本期、计算公式细节或回测验证。

### [3] 无名游资：主线前三 + 量价看涨的双条件参与

#### 1) 复盘先后顺序与决策流程

- 先用“九言公社”（转写名）工具看题材排名，排名**第一至第三**视为当下主线，重点研究前三，**第四不管**。[3, L18-L39]
- 再从通达信 ETF 排行榜找到对应主线 ETF，查看其持仓股；案例中看前五名持仓，逐一看日 K 量价和所谓主力建仓痕迹。[3, L40-L60][3, L117-L139]
- 明确参与顺序：**先确认主线，再在主线中挑个股，最后做技术/量价判断**。不能因某股看似有主力建仓就跳过主线条件。[3, L139-L149][3, L187-L220]
- 双条件同时满足才找机会介入并持有：题材仍属主线前三 + 个股技术形态看涨；任何一条破坏都退出。[3, L139-L150]
- 逻辑被概括为“价值 + 投机”：排名用于判断市场认可的价值，量价用于短线投机择时；作者同时承认并非百分百有效。[3, L218-L240][3, L263-L281]

#### 2) 明确因子、口径与阈值

- 第一层是市场/题材价值维度：是否当前主线前三，背后是否有利好或基本面改善。[3, L218-L230]

- 本文最明确的是“主线”动态排名口径：前三可参与，跌出前三退出，第四不研究；主线可因突发利好重新进入，例如机器人从非主线重新成为第一。[3, L27-L39][3, L153-L175][3, L187-L196]

#### 5) 次日正/负反馈与应对

- 正反馈是继续保持主线前三且技术形态看涨，可继续寻找介入/持有机会；突发利好可使原非主线题材重新进入观察范围。[3, L139-L150][3, L170-L196]
- 负反馈一为跌出主线前三：无论个股形态如何，无条件清仓。[3, L108-L116][3, L139-L150]
- 负反馈二为放巨量下跌/大阴线：视为出货或技术破坏，无条件清仓；到前高先减仓。[3, L67-L77][3, L108-L115][3, L265-L277]
- 若只有量价看涨、主线条件不满足，不因“主力建仓”而买入；若只有一个指标看涨，作者明确不会据此看涨。[3, L218-L240]

#### 6) 可量化项、需计算派生项、主观判断项（研究归纳）

- **可直接量化**：题材每日排名、是否前三、ETF 成分及持仓权重、股价、涨跌幅、成交量、K 线阴阳、前高、示例仓位。

- 原文没有给“放量”的倍数、主力成本算法、前三排名数据源计算公式、止损幅度或通用仓位规则；15% 与 10% 案例不能误写成双条件之外的第三个硬门槛。

### [4] 华东导弹：涨停板逻辑复盘、前置节点与可持续理解力

#### 1) 复盘先后顺序与决策流程

- 最基本动作是把当天所有涨停板认真过一遍，再逐股搜索上涨逻辑，知道市场正在炒什么；不要排斥已涨起来的方向，要顺着市场选择研究。[4, L18-L25]
- 对每个方向追问：有没有说法、可发展性、能继续讲的故事，以及后续是否还有消息持续刺激。[4, L23-L25]
- 适当阅读别人的观点以了解主流预期和对手盘，但如果自己的判断与市场多数高度一致，要反向打问号；后文又强调不要过于依赖别人判断。[4, L26-L27][4, L40-L41]
- 节点识别优先于机械贴周期标签：重点寻找情绪低谷转强，或低谷反弹后回调、再次确认强度并进入主升的节点。[4, L29-L35]
- 从市场已选出的几条并行逻辑中比较可持续性，顺趋势参与，不在单日高潮后接力；不要沉迷猜顶或提前猜大风格切换。[4, L43-L48]
- 通过每日看盘、自己的交易反馈和成功交易回溯培养节点感，把买点前置；等到一致公认上升/退潮再行动通常已滞后。[4, L35-L41][4, L54-L54]

#### 2) 明确因子、口径与阈值

| 因子 | 原文口径、数字和否定条件 | 来源 |
|---|---|---|
| 涨停板全量覆盖 | 每天至少过一遍全部涨停并查逻辑；案例称少时二三十只、多时七八十只，最多一百多只。等 **4 板**才发现题材被视为复盘偷懒，不是建议等 4 板确认龙头。 | [4, L18-L25][4, L50-L50] |
| 逻辑可持续性 | 看是否能持续发展、是否有后续消息刺激，是否跨出炒股圈成为社会话题，是否被官媒和各地官方账号持续报道；这是穿越周期、弱转强和抱团能否继续的核心。 | [4, L23-L25][4, L43-L44] |
| 情绪节点 | A 股只能做多，较好节点通常只有 **1—2 类**：冰点转强；低谷反弹后回调再确认强度、走向主升。 | [4, L29-L33] |
| 周期规律 | 没有“退潮后必修复、修复后必某阶段”的 100% 固定规律；核心被概括为板块轮动和“涨多了跌、跌多了涨”。 | [4, L33-L36] |

| 多线轮动 | 当前市场常有几条逻辑一起运行、反复切换；只要不在某板块单日高潮时接，布局同期仍可发展的几条逻辑也可行。 | [4, L47-L48] |
| 技术/盘口 | 没有单一指标、量、盘口或大单能判断真假弱转强和抱团持续；纯技术/纯盘口被认为难以相对量化交易建立优势。 | [4, L43-L45] |
| 周期龙头持续 | 一轮超短大周期开始时上涨的股票，往往可能持续到周期末；不是每个交易日重新猜顶。 | [4, L39-L40][4, L47-L47] |
| 封板率影响 | 两个主要因素是买入节点和自身做票成功率。尽量在情绪低谷试，而非涨高后强行买；扫板/排板则因重仓或分仓、个人历史胜率而异。 | [4, L52-L54] |

#### 3) 维度分类

- 信息/逻辑维度：涨停原因、故事发展性、后续催化、社会传播与官媒传播。[4, L18-L25][4, L43-L44]
- 情绪/节点维度：冰点、转强、回调确认、主升、轮动、高潮和一致；拒绝固定周期流水线。[4, L29-L41]
- 市场选择/龙头维度：顺市场选出的多条主线、周期初期核心持续、不过早猜顶。[4, L39-L48]
- 自我反馈/执行维度：当日开仓反馈、成功交易回溯、买点前置、节点与封板率、按个人模式选扫板或排板。[4, L35-L40][4, L52-L54]

#### 4) 主线、龙头、情绪锚和角色判定

- 主线不是凭空预判，而是市场已经选出、仍具逻辑发展性的方向；允许多条主线并行轮动，不要求唯一第一名。[4, L43-L48]
- 龙头思想体现为从市场最强几条线中选择最值得参与者，不捡便宜、不逆风口；周期早期启动的核心可能贯穿整轮，而非等 4 板才认识。[4, L39-L40][4, L47-L50]
- 能否穿越、真弱转强、抱团在指数回暖后继续上涨，关键都回到逻辑可持续性；纯技术指标无法替代该判断。[4, L43-L45]
- 情绪锚更多来自自己的开仓反馈和市场恐慌/修复感受，而非固定指标；大众一致观点用于识别滞后和一致风险。[4, L26-L27][4, L35-L41]

#### 5) 次日正/负反馈与应对

- 在较安全、市场发酵前或情绪低谷买入，即使个股当天炸板，次日也较容易修复；这是作者经验，不是保证。[4, L54-L54]
- 在市场高潮时买，即使当天封住，次日也可能直接走弱；因此不要在高潮后接力。[4, L48-L48][4, L54-L54]
- 若已看出退潮才空仓，往往已有多股跌停、亏钱效应接近极致；若等反弹后公认修复再买也滞后，所以应对是前置识别而非等标签确认。[4, L40-L41]
- 指数下跌时抱团、指数回暖后抱团下跌，或指数回暖后继续上涨，不能用“抱团”单一标签决定次日动作，要重新判断逻辑是否还能发展。[4, L43-L44]
- 市场切换往往比多数人猜得晚，顶只有一个；不要每天预判龙头到顶，优先顺势直到真实反馈改变。[4, L47-L47]

#### 6) 可量化项、需计算派生项、主观判断项（研究归纳）

#### 1) 复盘先后顺序与决策流程

1. **大盘大局观与赚钱效应**：先看指数走势、反弹是否构成反转，再看涨跌比、涨跌停比、高换手股表现、昨日涨停和今日跌停结构，最后整合消息与走势形成持续方向判断。[5, L32-L58]

4. **自己的交易与持仓**：重看盈亏、个股形态、概念与前三步热点是否契合，重新评估机会，决定继续持有、减仓或退出。[5, L132-L160]

6. **次日交易计划**：决定买卖标的、怎么买卖、高开还是回踩、买卖多少，综合形态、概念强度和指数环境。[5, L212-L247]
7. **阶段性复盘**：超短每周总结，其他级别可每月或每季度；同时总结个人胜率/盈亏与市场风格、指数阶段和时间窗口，决定操作大方向是否调整。[5, L248-L318]
