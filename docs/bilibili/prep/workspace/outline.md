# 调研报告提纲

1. Executive Summary：理想复盘是“市场环境 → 主线与角色 → 个股评分/仓位 → T+1 条件反馈 → 交易复盘”的闭环，不是更大的单一公式。
2. 逐文档提炼：每篇流程、因子、维度、角色、次日反馈；数字仅作原作者经验，不当已验证阈值。
3. 跨文档综合：共识、冲突、可量化/派生/主观边界。
4. 当前实现对比：已有 8 资产与两段式骨架；旧五维分/市场总仓位/定性 verdict 与新需求的语义差异。
5. 产品建议原则：评分与数据置信度分离、单票仓位与组合仓位分离、T 日评分与 T+1 触发分离、量化事实与 Agent 叙事分离。
6. 数据可得性矩阵：直接接口、现有字段未消费、本地派生、headless DOM、截图/OCR、登录态、不可可靠历史回补。
7. 技术方向输入：版本化资产/快照/因子，角色化策略， playbook 状态机，下游兼容，验证与样本外约束。
8. Limitations & Trade-offs：转写稿、经验阈值、数据口径、网页许可与稳定性、历史缺口、策略有效性未证明。
9. References：所有本地与外部来源。
